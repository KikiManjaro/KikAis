# Internationalisation (i18n) — KikAis

KikAis is fully internationalized. The UI, the technical labels, the
Documentation tab and the decoded AIS value labels are all localizable.

## Supported languages

| Code | Language |
|------|----------|
| `en`  | English (default / template) |
| `fr`  | Français |
| `es`  | Español |
| `de`  | Deutsch |
| `pt`  | Português |
| `it`  | Italiano |
| `nl`  | Nederlands |
| `zh`  | 中文 (简体) |
| `ja`  | 日本語 |
| `ru`  | Русский |

## How it works

- Uses Flutter's official `gen-l10n` tooling (`flutter_localizations` +
  `intl`). Configuration lives in `l10n.yaml`.
- Source strings live in **ARB files** under `lib/l10n/`:
  - `app_en.arb` is the **template**: it defines every key.
  - `app_fr.arb`, `app_es.arb`, … hold the translations.
- Running `flutter gen-l10n` (also triggered automatically by
  `flutter pub get` / `flutter run` / `flutter test` / `flutter build`)
  generates the typed `AppLocalizations` class in
  `lib/l10n/generated/`. **Never edit generated files by hand.**

## Language selection

- The UI language is chosen with the **language button** in the top bar
  (the globe icon, next to the theme button).
- Default is **Auto (system)**: the app follows the operating system
  language and falls back to English when it is not one of the supported
  ones.
- The choice is persisted in `AppSettings.localeCode`
  (`shared_preferences` key `locale`). `null` means "follow the system".

### How the code resolves the locale

`lib/l10n_ext.dart` exposes:

```dart
context.l10n            // -> AppLocalizations for the current locale
resolveSystemLocaleCode(locale)  // nearest supported language, default 'en'
```

`MyApp` (`lib/main.dart`) wires `supportedLocales`,
`localizationsDelegates` and `locale` on `MaterialApp`.

## Conventions

- **Key naming**: keys are `camelCase`, prefixed by area
  (`tab*`, `send*`, `reception*`, `stats*`, `sim*`, `map*`, `editor*`,
  `field*`, `f*` for decoded message fields, `doc*` for the Documentation
  tab, `msgType1..27` for the 27 AIS message types, `log*` for the
  forwarder log lines, `language*`/`theme*` for the menus).
- **Interpolation**: use ICU placeholders, e.g.
  `"statsFeedFilter": "Feed: {filter}"` generates
  `String statsFeedFilter(String filter)`.
- **Plurals**: use ICU plurals, e.g.
  `"receptionDroppedSentences": "{count, plural, =0{...} =1{...} other{{count} ...}}"`.
- **Placeholders must be preserved** in every language with identical names;
  gen-l10n fails otherwise.
- **Do not translate**: protocol acronyms and units (AIS, NMEA, AIVDM,
  MMSI, MID, IMO, SOG, COG, ROT, ETA, DTE, RAIM, EPFD, DAC, FID, GNSS,
  UDP, TCP, VHF, TDMA, SOTDMA, GMSK, HDLC, NRZI, VDES, SART, MOB, EPIRB,
  SOLAS, `kn`, `°`, `m`, `×1`), proper nouns (KikAis, Kikistream.io,
  Sinagot, OpenStreetMap, Esri, CARTO, OpenTopoMap, Voyager, Positron,
  Dark Matter), IP addresses, ports, host names, NMEA sample sentences,
  and basemap legal attributions.

## Adding a language

1. Copy `lib/l10n/app_en.arb` to `lib/l10n/app_<code>.arb` and set
   `"@@locale": "<code>"` as its first key.
2. Translate every value; keep every key and every `{placeholder}`.
3. Run `flutter gen-l10n`.
4. Register the language in `lib/l10n_ext.dart`
   (`kSupportedLocaleCodes`, `_languageName` in `lib/swipper.dart`).
5. Add a native language name in every ARB (`languageXx` keys) so it
   appears in the language menu.
6. Add the country-name and value-label maps for the locale (see below).
7. Run `flutter gen-l10n`, `flutter analyze` and `flutter test`.

## Data tables (countries and decoded values)

Two extra tables are translated outside the ARB system because they are
large keyed dictionaries (keyed by the canonical English string):

- `lib/l10n/translations_data_<code>.dart` — two `const` maps per locale:
  - `kCountryNames<Code>`: canonical English country name → localized
    (used everywhere a country is displayed: map filters, simulation MID
    search, Documentation MMSI lookup). Lookup helper:
    `localizedCountryName(english, context)` in `lib/l10n/country_names.dart`.
  - `kValueLabels<Code>`: canonical English AIS value label (from the
    decoder's `BinaryConverter`) → localized. Lookup helper:
    `valueLabel(l10n, english)` in `lib/value_labels.dart`.

The `lib/ais` package is deliberately left untouched (it still produces
canonical English values); translation happens at the UI boundary.

## Checking translation completeness

- `flutter gen-l10n` writes `lib/l10n/untranslated.json` listing keys that
  are missing from a locale. An empty `{}` means every locale is complete.
- The 10 language classes are generated under `lib/l10n/generated/`.

## Notes

- The Documentation tab content (chapters, glossary, cheat sheets,
  message catalog, timelines) is fully translated through `doc*` keys.
- Widget tests use the `withLocalizations(...)` helper
  (`test/l10n_test_utils.dart`) so they always assert against English.
